`public/img/accessories/` (sin hotlinking). Alt descriptivo en todos

## Convenciones

- **Fotografías oficiales de Apple España** (JPEG 1200×1200)
  descargadas desde `store.storeimages.cdn-apple.com/1/as-images.apple.com/is/{SKU}?wid=1200&hei=1200&fmt=jpeg&qlt=95`.

  se encontró en el CDN; la PR correctiva las sustituyó todas por

## Notas

- El proceso de descarga usa `curl -H "User-Agent: Mozilla/5.0"`
  sobre el CDN público `store.storeimages.cdn-apple.com` — el mismo
  URL patrón que sirve las fichas oficiales de `apple.com/es`.
- No se aplican transformaciones (recorte, recompresión) sobre los
  JPEG. Las imágenes conservan la calidad original.
- La escala visual (`scale > 1` para adaptadores pequeños,
  `padding: compact` para cables) se aplica en render mediante el
  helper `AccessoryImage`; los datos son tipados y limitados.
